# BrokeDJ — by Swir

**Zero cost. Full control.**

BrokeDJ is an open-source DJ workstation project built with C++20 and JUCE, targeting Windows 11 x64 first.

> Repository initialization. This is not a finished DJ application or a production-ready release.

## Product direction

Four decks, a professional mixer, extensible effects, a sampler, a music library, MIDI controllers, external VST3 effects and stem workflows are the product goals. Planned capabilities are not implemented capabilities.

## Development

The first milestone establishes the native application, independently testable audio core, reproducible CMake builds, and an honest feature roadmap.
