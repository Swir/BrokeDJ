# M1 one-click hardware witness

Run `START-M1-HARDWARE-WITNESS.cmd` from the packaged BrokeDJ folder to start the existing M1 hardware witness against the adjacent `BrokeDJ.exe`.

Evidence is stored under `%USERPROFILE%\Documents\BrokeDJ-M1-Evidence`.

Playback, device switching, device loss/recovery, cue routing, and listening checks remain manual hardware qualification and must stay fail-closed when evidence is missing.
